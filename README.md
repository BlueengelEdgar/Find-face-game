# 寻找人群 V0.3 · 漫画风试玩版

现有 Phaser 3 + Vite 项目迭代。使用确认后的全球化漫画动画方向，降低饱和度；150 个独立人物文件，不再使用旧简化 SVG 或柔绘日系人物作为游戏美术。

## 直接试玩
交付包包含单文件 `play.html`：解压后用桌面浏览器打开，不需要安装依赖、登录、数据库或图片服务器。脚本、样式和全部人物已嵌入。手机系统的文件查看器可能不执行网页脚本，手机真机请使用本地服务或后续经审核发布的站点，不要将文件查看器等同 Safari。

本次提供的是离线试玩包与开发分支，没有自动公开部署。构建命令生成 `dist/find-crowd-v03.html`，交付 ZIP 由 `python3 scripts/package-trial.py` 生成。

## 内容
- 第一关：10 人，较大人物、自然错位、前后遮挡。
- 第二关：正式 150 人，固定且可复现的非网格人群构图，逐像素透明命中。
- 另提供 35 人密集样板用于观察美术与误触，明确标为样板，**不是把第二关改成 35 人**。
- 每批 5 个唯一目标、全部找完才通关；人物原位变暗打勾、错误不罚时、计时、暂停、重开、结算及模拟排行榜保留。
- 返回按钮打开菜单并暂停；返回游戏后需手动继续。
- 修复切关/重开/重排时旧人物点击对象残留的“幽灵命中”。

## 屏幕适配
dvh 与安全区域适配，页面不滚动，五目标保留完整空间，画布无手势缩放。平板/PC 使用竖向游戏面板。

150 人关要求人物区宽至少 340 CSS px、高至少 470 CSS px，且高宽比至少 1.48。人物宽度有下限，不无限缩小；短屏不满足条件时明确锁定 150 人入口，可玩 10 人与 35 人样板。正式人数仍保留 150。窗口在 150 人局中变窄/变矮会自动暂停，恢复足够视野后手动继续。

## 本地开发
Node.js 22+（验证 24.19.0）：
```sh
npm ci
npm run dev
npm test
npm run build
npm run test:browser
```
开发路径 `/Find-face-game/`；不需要另建 Git worktree。
`npm run test:offline` 只执行离线文档加载及三个模式通关。

## 工程结构
- `src/characters.js`：150 个稳定 ID、文件及面部锚点。
- `public/art/v03/character-001.webp … character-150.webp`：独立透明人物资源，目标和墙体共用相同文件。
- `art-source/v03/`：10 张原始素材页、角色描述、提取记录；仅用于维护，不进入站点的 public 资源。
- `src/art-layout.js`：首关与样板构图、屏幕能力条件。
- `src/crowd-150-layout.json`：基于实际 alpha 遮挡优化并冻结的 150 人布局，不是每次随机生成。
- `src/scene.js`：前后层级、逐像素命中、完成标记、正确销毁旧对象。
- `src/model.js`：独立玩法模型；`src/main.js`：界面和流程。
- `scripts/extract-art.mjs`：提取独立素材（ImageMagick 7，仅资源维护需要）。
- `scripts/measure-layout.*`、`scripts/fit-crowd.py`：只读图片 alpha 并生成测量/位置数据；Python NumPy、Pillow 仅维护工具需要，运行和构建游戏不需要。
- `scripts/build-portable.mjs`：构建自包含试玩 HTML，并检查脚本未在注入时被改变。
- `tests/model.test.js`：13 项模型、配置、资源与布局回归。
- `tests/v03-browser.js`：触摸、关卡切换、完整通关与离线回归。

## 当前验证与限制
五种视口：390×844、320×568、768×1024、1440×1000、1366×768。除短屏按设计锁定 150 人外，其余视口都完成全部模式。另用断网内联文档完成三个模式，验证单文件包零网络请求。详见 [试玩验证记录](docs/V03-PLAYABLE.md)。

当前环境浏览器策略禁止 file:// 导航，因此单文件包用断网文档冷启动验证；真实下载后双击打开及 iPhone/iPad Safari 文件行为需在本机确认。Chromium 触摸模拟不能替代真实 Safari、安全区域、工具栏变化、手指精度和低性能设备测试。

150 人仍属于高密度挑战，自动精确坐标点击通过不代表人眼辨识与真实手指误触已验收。人物文件合计约 5.8 MiB，单文件 HTML 约 8.8 MiB；原有 Phaser 构建体积提示仍在。
