# 寻找人群 · 第一阶段灰盒原型

Phaser 3 + JavaScript + Vite，本地运行，无服务器、登录或数据库，不依赖外部图片服务。

## 开发
需要 Node.js 22+（已在 Node 24.19.0 验证）。
```sh
npm ci
npm run dev
npm test
npm run build
```
浏览器打开开发服务器即可游戏。不要将开发服务公开部署。
使用现有隔离检出目录，无需创建 Git worktree。

## 玩法
选择 10 人热身关或 150 人人海关。寻找底部本组 5 个目标；正确人物保持位置，变暗并打勾。组内全部完成后轮换，直至所有人物完成。
错误点击仅提示、不罚时。支持暂停、重新开始；页面进入后台自动暂停，回到前台需手动继续。
通关显示实际用时与明确标注的模拟排行榜（固定示例，不是真实成绩或在线排名）。
每次重开重新打乱唯一目标队列。计时从关卡可交互时开始，排除暂停时间并在通关时冻结。

## 文件
- `index.html`：页面、控制栏、目标栏及结果弹窗
- `src/main.js`：界面与游戏流程
- `src/scene.js`：Phaser 头像墙、点击、完成及暂停显示
- `src/model.js`：唯一目标队列、五人分组、计时与状态
- `src/levels.js`：独立关卡配置、固定视野错位布局
- `src/avatars.js`：150 个本地生成的独特 SVG 临时头像
- `src/style.css`：手机竖屏优先的响应式样式
- `tests/model.test.js`：8 项模型、布局、头像测试
- `tests/browser.js`：Chromium 自动化点击与通关测试
- `package.json` / `package-lock.json`：命令及锁定依赖
- `.gitignore`：忽略依赖、构建与测试输出

## 浏览器自动化
`npm run test:browser` 使用系统 `/usr/bin/chromium`，启动本地 5173 端口，测试结束关闭自己启动的服务。运行前确保端口空闲。
覆盖 390×844、320×740、768×1024、1440×1000 视口；每种尺寸点击两关全部 160 人，检查错误反馈、暂停冻结和输入阻断、重开、目标同步、通关弹窗和 JavaScript 错误。
截图输出到 `/tmp/find-face-<宽度>.png`。
如果其他系统的 Chromium 路径不同，需调整测试脚本中的 executablePath。

## 原型限制与待人工验证
- 临时头像带编号，并通过肤色、发色、衣色及细节区分。身份唯一，但不代表所有组合在人眼看来都足够容易辨认。
- 固定 390×540 逻辑视野，无游戏内缩放和平移。150 人关在窄手机屏幕上点击区域较小，需真机评估。
- 页面允许纵向滚动以适应短屏；人物墙内部固定、不滚动。viewport 限制移动端缩放，但部分浏览器或辅助功能设置可覆盖该限制，桌面浏览器自身缩放不由游戏控制。
- 未完成真实 iPhone/iPad Safari、Android Chrome、Firefox、触屏误触、多指手势及低性能设备测试。自动化 Chromium 视口模拟不等同于这些测试。
- 需要后续调整美术、布局密度及触控体验；当前头像轻微错位，允许轮廓接近，不遮挡主面部。
- Phaser 初始构建包约 1.49 MB（gzip 343 KB），Vite 有包体积提示；尚未做加载性能优化。
