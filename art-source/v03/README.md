# 本地美术源文件

10 张 AI 生成的漫画人物素材页，每页 15 个独立半身角色，打包为 5 列×3 行。人物生成方向以用户确认的全球化漫画动画效果图为参考，降低饱和度、避免霓虹边缘；五官、年龄、发型、帽子、眼镜、胡须及服装组合各异，禁止编号与标志。

cast.json 记录各页逐格角色描述；group 为 0 起始，角色 id = group×15 + slot（slot 也是 0 起始）。sheet-01.png … sheet-10.png 保留原始输出，extraction.json 保留逐格裁切坐标和主体包围盒。

生成规则：
- 整页 4:3，5×3 等格，每格 4:5，单人透明背景，不能与相邻人物重叠。
- 统一全球漫画动画画法：粗细变化墨线、色块阴影、细网点；非旧 SVG 或半写实柔绘。
- 自然肤色、丹宁蓝/鼠尾草绿/陶土/奶油/低饱和赭色/梅紫；多样脸型与年龄。
- 无文字、编号、标志、背景，完整头发/帽子，肩膀至胸部。
- 实际生成结果与格线有小幅偏移，提取工具去除主体包围盒外的残片，保留比例和 alpha 边缘；不能假定生成格线就是最终命中区域。

维护环境：ImageMagick 7.1.1-43；npm run art:extract 重新导出全部 150 张 WebP。脚本不生成新身份，只从已提交源文件重现切片。工具不得用于用颜色换皮冒充新人物。

布局分析使用 Python NumPy、Pillow 读 alpha，优化后仅写 src/crowd-150-layout.json，不改人物像素。输出是固定的归一化坐标，运行时无需这些维护依赖。
