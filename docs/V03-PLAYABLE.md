## 布局测量
150 人构图先采用不等长行和错位作为起点，再使用实际 WebP 的 alpha 优化位置与有限尺寸调整，冻结为坐标文件。运行时不重新随机排墙，不依赖优化工具。
同一人物墙在相同视口可复现，目标队列每局打乱但不重复。

每角色的中心面部区域 11×11 采样，结合实际不透明像素与前后层级统计。这里的可见率不是整张人物图可见率，也不是人眼辨识验收：
- 390×844：150 人最差受检可见率约 97.5%，图片宽约 46～50 CSS px。
- 768×1024：150 人最差约 98.3%，图片宽约 59～63 CSS px。
- 1440×1000：150 人最差约 98.3%，图片宽约 57～61 CSS px。
- 1366×768：150 人最差约 98.3%，图片宽约 43～46 CSS px。
图片宽含头肩与透明边缘，不等于整张脸的宽度或点击热区直径。

小屏 150 人的实际手指精度与人眼辨识度必须人工试玩。人物宽度不低于人物区宽度的 12.5%，未通过无限缩小达成。人物区不足 340px 宽、470px 高或高宽比不足 1.48 时，明确禁用正式 150 人，不自行减少其人数。10 人与 35 人保持可玩。
