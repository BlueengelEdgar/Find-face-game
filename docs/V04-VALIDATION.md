## 自动化
- npm test：17/17通过，覆盖任意唯一身份队列、精确错误加时、找到/空白不罚、批次状态、锁定输入、动画停表、后台与批次嵌套暂停、整局完成、资源唯一性和UI。
- npm run build：通过，仍有原Phaser大包提示。
- npm run test:browser：退出码0，五种网页/离线视口，总计395次正确触摸。
- 每次非末批均检查五卡一起退出180ms、五卡进入220ms与15ms错峰、总配置460ms。锁定测试在动画阶段同步派发Touch事件，经过实际Phaser输入路径，验证不加时、不完成目标；其他寻找、误点、长按、拖动使用Chromium触摸输入。
- 正确点击不加时，快速重复误点逐次+3s，长按/拖动一次仅罚一次；从空白按下拖入人物不触发；已找到人物不重复罚。
- 错误事件当帧检查红叉、+3s与330ms计时器高亮，随后检查反馈清除。振动API替身验证30ms调用、一次手势一次、缺失/抛错不影响游戏。
- 第一关结算只有NEXT LEVEL，无排行榜；第二关有模拟标识与重新挑战。两个关卡都完整通关，下一关及重新挑战重置时间与惩罚。
- 视口缩小/恢复保留找到状态；页面不溢出，底部五目标完整，顶部无额外按钮或开发提示。
- 冷启动断网内联文档完成两关，零网络请求；环境策略不允许file://导航，因此不声称实际file://打开已测试。

## 关键区域面积与填充度
以**每个不透明源像素**审计上部头型轮廓：图片中面部锚点以上、向下延伸0.18图高，包含头发/帽子/脸/眼镜的主要轮廓。区域是保守的上部人物alpha掩码，可能包含少量颈部；不是仅采样脸中央。五官中央单独保护。按前后层级及实际图片alpha计算被遮挡和越界面积；已找到标记与短暂反馈不计入初始NPC遮挡。

这里的“关键区域”是可复现的图像掩码审计，不是人工逐角色语义分割的替代。发型/帽子等局部还需结合实际截图人工确认；不声称每个子部件的遮挡率都相同。
